# AI Employee Specs

One file per Digital Employee type (Receptionist, Secretary, Sales Rep, Support, HR, Finance, Marketing, Ops Manager). Each should conceptually define:

- Identity
- Role
- Responsibilities
- Permissions
- Tools
- Knowledge
- Memory/context
- Tasks
- Workflows
- Communication channels
- Human escalation
- Performance metrics
- Auditability

Do not lock implementation details prematurely — only what's actually decided.
